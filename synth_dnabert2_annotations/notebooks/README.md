# Analysis Notebooks

This directory contains Jupyter notebooks for data analysis and visualization.

## Contents

### phase1_data_analysis.ipynb

Analysis of InpactorDB2 dataset and synthetic genome generation results.

**Analyzes**:
- TE family distribution across species
- Sequence length distributions
- Classification hierarchies
- Species coverage statistics

**Usage**:
```bash
jupyter notebook phase1_data_analysis.ipynb
```

**Requirements**:
- Jupyter (included in phase1 requirements.txt)
- pandas, matplotlib, seaborn
- InpactorDB2 analysis CSV files (generated by `phase1/scripts/analisis_inpactordb2.py`)

## Adding New Notebooks

Place additional analysis notebooks here following the naming convention:
- `phase1_*.ipynb` - Phase 1 related analysis
- `phase2_*.ipynb` - Phase 2 related analysis (training, evaluation)

## Running Notebooks

From the repository root:

```bash
# Activate appropriate environment
conda activate te_phase1  # or dnabert2_te for phase2

# Start Jupyter
jupyter notebook notebooks/
```

## Notes

- Notebooks are provided for reproducibility and exploration
- Some notebooks may require generated data from the pipeline
